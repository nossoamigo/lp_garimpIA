# Página de links do garimpIA | Achados de Ouro

Página única (HTML puro, sem build) para o link na bio do Instagram. Leva ao WhatsApp e ao Telegram.

## Trocar um link
Edite os dois `href` em `index.html` (WhatsApp e Telegram), faça commit e push. O GitHub Pages atualiza em ~1 minuto.

## Logo
Coloque o arquivo `logo.png` (quadrado, ao menos 512x512) nesta pasta. Sem ele, a página mostra o ⛏️.

## Publicar no GitHub Pages
1. No GitHub, crie um repositório **público** (ex.: `ladingpage_garimpIA`). Páginas de repositório privado exigem plano pago.
2. Nesta pasta: `git remote add origin <endereço do repositório>` e `git push -u origin main`.
3. No repositório: Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.
4. O endereço fica `https://<seu-usuario>.github.io/<nome-do-repositório>/`. Esse é o link que vai na bio do Instagram.

Nada de segredo vai neste repositório: só o HTML, o logo e os links públicos de convite.
